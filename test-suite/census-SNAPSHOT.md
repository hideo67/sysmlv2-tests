## What this is

Every derived property of the metamodel (328 properties marked `derived="true"` in the Pilot's `org.omg.sysml/model/SysML.ecore`, commit `378a8700c0`, https://www.omg.org/spec/SysML/20250201) is read on every element of each corpus that carries it. A cell is `values/answered`: how many of the carrying elements the MDK answers with a non-empty value, out of those it answers at all; `unanswered` means the MDK does not derive the property (it says so, or it raises). The element set is the corpus as written: each document's root namespace, its owned relationships that are not implied, and their owned related elements, transitively.

An empty value is not wrong in itself (a part def with no features has an empty `ownedFeature`). The signal is the comparison: the Pilot, the OMG reference implementation, is the reference column, and a property is compared over the metaclasses both MDKs have elements of, so that an element one MDK creates and another does not (see Element sets) does not move the other's rate. Listed below: properties an MDK does not answer, answers empty where the reference has values, or fills at a rate more than 25% below or above the reference's.

Generated by `census_report.py` from `results/census-<suite>.json` (`run-census.sh`). Property list and corpora: `data/census/derived-properties.json` (`data/gen_census.py`).
